# Stage 0 IR 内部设计 v0.1

> 当前实现契约，2026-11-17。不是语言语法标准；总体方向见[架构草案](self_hosting_compiler_design_v0_1.md)，实际范围见[基础编译原型](parser_subset_v0_1.md)。

## 表示与基本块

AtriIRProgram → AtriIRFunction → AtriIRInst[]，函数另有调用实参索引数组。函数索引引用调用目标，指令索引引用函数内定义；名称及原始源码区间用于 Dump/诊断和外部符号输出，输入源码必须保持存活。Program 另拥有 strings 数组及各项解码字节，length 不含额外终止零字节，destroy 时释放。

值类型为八种定宽整数、bool、多级数据指针、固定数组和名义聚合，函数签名记录所有参数及返回值。普通函数有显式 block_count，入口块 0 隐含存在，其余块用 label immediate 标识。jump、branch、return、unreachable 为终结指令，每块必须恰有一个终结。branch 的条件为 bool，分别记录真/假目标。

指针类型 ID 保留一层目标的编码，额外层数编码在高位。编译器用同一整数类型 ID 检查目标和层数，无需分配额外的类型记录。`LOAD`、`STORE` 和 `ADDRESS` 仍按直接目标检查，`PTR_OFFSET` 和 `PTR_DIFF` 用直接目标大小。各级指针在 Windows x64 上均占 8 字节，逐层访问生成所需的实际访存，ABI 和运行期表示与原有数据指针一致。

external_c 函数只记录签名与 variadic 标志，parameter_count 仅为固定前缀数量；非外部定义暂不允许 variadic。external_c 函数，instruction_count、argument_count 和 block_count 必须为 0，不生成函数体、栈帧、CFG 或展开信息。call 记录全部实际参数，固定前缀精确匹配、尾部检查已完成 C 默认提升的类型。call 继续通过函数索引统一引用普通定义和外部声明。extern(C) 不进入内联或常量解释执行。

param、const、unary、binary、cast、compare、call、load、address、ptr_offset、ptr_diff、string、zero 产生值，void call 例外。string.type 必须为 *u8，immediate 是 Program.strings 的稳定索引，不是宿主或目标地址，优化/内联复制指令时保留此索引。local 是内部存储对象，field/index 是内部位置，均不能作为普通值；store/控制指令不产生值；NOP 标记删除的指令。值必须先定义再使用，在可达 CFG 上定义块必须支配使用块。本轮不引入 phi；跨分支/回边的可变状态由显式局部存储表达。

整数常量用 uint64_t 保存类型位宽内的位模式，位宽之外必须为 0；有符号解释不依赖宿主 C 溢出。bool 常量仅允许 0/1。指针 const 只表示 null，不能借常量字段伪造非空宿主地址。

## 模块与全局存储

AST 保留 import、export、全局声明与模块文件区间。名称表绑定到原函数/全局 ID。IR 函数保存 module ID，仅根模块的 main 使用入口符号。Program.globals 保存全局类型及编译期常量标记。标量初值使用 bits，数组和 struct/union 初值使用 Global 自有的 data/data_size，长度精确等于目标布局大小，destroy 逐项释放。两种表示互斥，聚合不能标记为编译期常量。共享全局不按导入次数复制，编译期常量引用折叠后不输出独立数据对象。

LOCAL.immediate 为 0 时表示原栈对象，非零时表示 globals 索引 + 1 的全局存储位置。LOAD/STORE/ADDRESS 继续引用该稳定位置；Verifier 检查索引、类型及不写编译期常量。后端对全局位置使用 RIP 相对寻址，不分配栈对象，不插入锁或原子操作。优化器保留 STORE 和相关存储位置，含访存函数不作为叶函数内联目标。常量解释器拒绝读取/写入运行期全局，不执行宿主全局访问。

全局初始化暂以临时函数及常量义务使用现有解释器求值；求值后提取初始位模式、替换全局编译期常量引用并删除临时函数。结构体全局的花括号初始化递归展开为标量叶子义务，字段默认值借用既有临时函数；先分配全零目标字节，再将求值结果按字段偏移和 Windows x64 小端位模式写入，不 memcpy 宿主整数。嵌套结构体和字段数组采用同一遍历，不让解释器执行聚合内存操作。物化全次编译限 100000 节点/256 深度；无显式子项的零大小子树直接跳过，重复/未知字段和数组越界项仍诊断。

Verifier 检查静态缓冲区长度及非 union 路径上的嵌套 bool 的 0/1 表示、指针的全零表示，忽略填充字节；union 表示边界见下节。布局和缓冲区检查先于内容遍历，内容检查每对象限 100000 节点/256 深度。Dump 输出聚合初始字节，后端按自然对齐发出完整 .byte 数据（包含填充）；零大小全局使用一字节地址锚点，IR data_size 和语言 sizeof 仍为 0。每个聚合全局增加布局大小的编译器缓冲区及对应静态存储，叶子义务另占临时编译内存；默认零化和填充有数据体积成本，不产生用户程序的初始化调用或隐式堆分配。临时函数不进入最终调用图；指针静态初始值当前仅为 null，聚合调用/复制初值、聚合常量及静态重定位初始化尚未实现。

## 结构体布局、值与调用

Program.structs/fields 保存名义类型、字段类型、偏移、大小/对齐和标量默认值；动态结构体类型 ID 与其指针 ID 分区编码，Verifier 检查索引有效性。模块名称表包含结构体声明身份。AST 记录字段默认表达式、指定初始化项及 FIELD 表达式；字段默认值借用独立常量求值，临时函数及调用在运行期 IR 前删除，不生成隐藏的运行期默认值函数。

ZERO 产生结构体零值快照；FIELD 为存储位置（不是普通值），left 引用原对象位置、结构体值快照或显式解引用后的结构体指针，immediate 为 fields 的稳定索引。LOAD/STORE 可复制完整结构体，ADDRESS 可取得支持的标量或聚合位置的指针。局部结构体有稳定存储；字段读写定位原对象，值传参和赋值则取得快照。Verifier 检查字段所属名义类型、自然布局、内容类型、支配关系和地址目标。

Windows x64 后端为结构体对象/快照分配自然布局的栈空间，间接调用实参副本按 16 字节对齐；复制使用易失寄存器和定长分块 mov，不引入运行期堆分配。1/2/4/8 字节结构体走整数寄存器/栈槽，其余正大小结构体走独立副本指针，返回使用隐藏首参及 RAX 缓冲区地址。调用区按最大参数及副本需求复用，隐藏返回地址单独保存，普通参数的位置计入隐藏首参。空结构体当前内部采用零内容、单实参位置约定，C 按值接口拒绝零大小结构体。

含结构体、结构体指针或 FIELD 的函数暂跳过旧单块优化/内联，防止错误重映射对象和快照；尚无聚合复制消除或标量替换。结构体全局的静态对象物化见上节；结构体 := 和聚合默认表达式继续诊断为未支持，常量解释器不把结构体临时存储当作宿主地址执行。

## 无标签 union 的表示

AST AtriStruct 和 IR AtriIRStruct 增加 is_union，沿用已有 structs/fields 数组、模块名义类型 ID 和指针 ID；atri_ir_is_struct 表示这个共享名义类型区间，不能据其名称假设字段互不重叠。union 的字段 offset 均为 0，size 为最大成员大小向最大 alignment 补齐；Verifier 按 is_union 区分顺序布局与重叠布局，同时检查非空完整定义、成员范围和统一大小/对齐。AST Dump 显示 Union；IR Dump 的共享 @struct.ID 定义带 union 标识。

成员读写/取地址继续使用 FIELD/LOAD/STORE/ADDRESS，复制、参数/返回和后端 ABI 分类不增加新指令。union 初始化只生成整块 ZERO 及显式选中成员的写入，不为其他重叠成员生成默认值操作；全局物化也只递归选中成员。全零初始化是实际的初始化成本，不等于零指令；不增加运行期有效成员标签、检查、分配或析构调度。每个类型描述增加一个编译器标志，用户对象仅占自然布局大小。

全局静态字节可按整数成员保存任意合法整数位模式，即使同一位模式不是其他 bool/指针成员的合法表示。因此 Verifier 在静态内容遍历中跳过 union 内容，继续验证外围结构体的非 union 字段、缓冲区长度和全部类型布局；不能把重叠字节同时按所有成员验证。初始化表达式本身仍精确检查选中成员类型、强制标量求值及 null 静态指针边界。运行期读取合法性由程序保证，没有隐含动态检查；不把这个跳过视为开放非法 bool/地址。

常量解释器仍不执行聚合值/内存，union :=/#run 聚合结果及聚合调用/复制静态初值继续拒绝。优化器现有名义聚合/字段保护也覆盖 union，未增加复制消除；C 兼容性检查遍历所有成员以排除零大小等非 C 成员，测试绑定生成真正的 C union，而非替代结构体。

## 固定数组与索引

Program.arrays 拥有元素类型和逻辑长度，按二者线性去重；数组使用独立类型 ID 区间，指针可指向数组，结构体仍保持名义身份。AST.array_types 保存长度表达式 ID 和元素类型区间，避免从文本重新猜测表达式边界。所有数组布局遵循连续元素、元素对齐和零长度规则；按值递归布局检查穿过数组，但指针边不构成按值循环。

布局阶段的长度求值支持字面量、可见整数常量、整数 cast、sizeof/alignof 和基本整数算术，遵循局部/for/参数遮蔽及定义模块名称解析。采用整数计算公共函数，不把宿主有符号溢出当作目标结果；类型未定的长度按 i64。长度依赖求值和索引静态传播均设 100000 步/256 深度上限，避免重复依赖指数展开。布局求值目前不能调用函数，不与完整 #run 求值能力混同；去重和词法常量查询仍为原型实现，没有缓存性能承诺。

index.type 是元素内容类型，left 是数组位置/值快照或指向数组的值，right 是八种定宽整数之一的索引，不能是 bool；index 本身是位置，load/store/address 引用该位置。后端在 index 执行时按元素大小缩放并把地址保存到 8 字节临时槽，后续使用不重新求值，也不借用可能被调用实参占用的地址寄存器。嵌套索引/字段保持原对象定位，临时数组只能读取。索引可静态确定越界时在可选优化前诊断，不插入运行期比较或失败调用。

数组复用聚合 zero/load/store、参数/返回和定长复制；不足的初始化项递归使用元素默认值，显式元素按列表顺序求值。含数组或 index 的函数跳过旧单块优化/内联。无隐式堆分配，但零初始化、快照、复制和索引地址槽均有实际成本，尚无复制消除保证。直接 extern(C) 按值数组拒绝；C 兼容结构体内嵌数组按结构体布局/ABI 处理。

## 整数转换与目标布局查询

cast.type 是目标整数或数据指针类型，left 引用同一类别的已定型源值。Verifier 检查整数到整数或数据指针到数据指针及定义支配关系，不允许借 cast 开放 bool 整数、指针整数或聚合值转换。数据指针 cast 传递地址位模式，不增加目标布局/生命周期证明；通常仍拒绝编译期指针转换。转换的位模式由 atri_integer_convert 统一定义，常量解释器、折叠、内联重映射和 DCE 均处理该指令；同宽转换保持位模式，源 i32 扩为 64 位时做符号扩展，u8 来源为零扩展，窄化保留低位。

后端先规范化 8/16 位临时值，再按源类型执行必要的 movsxd/低位截断，32 位目标保存低 32 位；无需运行期范围比较。u64 内容使用 QWORD，除余使用零扩展 RDX 的 div，排序使用无符号 setcc。u64 常量 Dump 按无符号十进制打印，保持高位数值可检查。

sizeof/alignof 的 AST 保存类型区间，在布局完成后直接降低为 u64 const，不新增运行期 IR 操作或语言运行时。指针自身大小不依赖目标对象布局。数组长度中的嵌套查询、转换及常量依赖使用共享预算；显式按值循环通过布局状态诊断，其余循环查询会触发资源诊断。所需的扩展/截断和原型值栈槽仍有实际成本，未测量性能或承诺复制最少。

## C variadic、void 与 opaque

C 尾参的 i8/u8/i16/u16/bool 提升由独立 c_promote 指令表达：结果必须为 i32，源必须是 i8/u8/i16/u16/bool。它是 C 边界转换，不改变普通表达式的隐式转换规则。常量折叠按源类型符号/零扩展为 i32 位模式，DCE/内联重映射必须跟踪 left；后端按规范化的 32 位值传递。C 兼容聚合尾参继续使用现有大小分类、独立实参副本和隐藏返回地址，没有单独的变参打包、计数或堆分配。

void 只作为函数返回类别；不是合法对象或普通操作数类型。void call 没有可使用的结果，后端不为其分配结果槽或保存 RAX；void return 的 left 为 ATRI_NONE，不加载返回值。Verifier 只允许签名返回、call、return 及删除后的 NOP 使用 void 类别；参数、对象、常量和可用值拒绝 void。优化器不得把 ATRI_NONE 当值 ID，void 函数暂不内联。解释器可执行普通 void 函数作为语句，但 void 不是 #run/常量结果；外部 C call 仍拒绝在编译期执行。

Opaque 结构体记录身份和 opaque 标志，不提供对象布局；IR 保留 size=0/align=1 作为未布局元数据，不能将它当零大小完整对象。指针有效性只要求目标声明存在，按值布局、字段/解引用读写和 sizeof/alignof 对象查询拒绝 opaque。测试绑定只生成前置类型名，不伪造 C FILE 定义。数据指针 cast 不改变访问权限；有限的 null/局部地址返回诊断会穿过指针 cast。

variadic 标志与 opaque 类型描述只占编译器元数据，尾部检查按实际实参及有界布局递归处理。后端使用实际参数数量布局调用区，包括隐藏返回参数平移；首轮没有浮点输入，未来需另补默认浮点提升与 Windows x64 的 XMM/整数寄存器双写。不把当前整数/数据指针/普通聚合测试当作完整 ABI 证据。

## 局部对象与访存

local.type 是对象内容类型，可含结构体/数组；local/field/index 位置不能作为普通值或指针传给函数。address 取得全部整数、bool 和聚合位置的地址；load/store 接受内容类型匹配的位置或数据指针，*void/opaque 目标不能访问。store 没有结果值。

含控制流或运行期短路表达式的函数，可变局部使用 local/load/store；参数仍是只读值，编译期常量保留结果值。直线函数中，未取地址变量保留值映射，赋值更新映射；取地址标量具有稳定对象，名称与指针访问观察同一存储。预扫描保守按名称匹配，可能多分配对象，不做逃逸优化。

复合赋值在 AST 上保存 compound/op，不复制左侧表达式。降低时先计算位置、取得旧值，再降低右侧并生成 binary/ptr_offset 和 store（或更新值映射）。结果必须保持目标类型；常量/只读参数/临时值不能作为目标。

binary 支持八种整数的算术、位运算和移位；移位右侧可为另一整数类型，必须检查其完整位模式，不能先截断到左侧类型。字节字面量直接降低为 U8 const，字符串降低为 PTR_U8 string；已删除独立 CHAR/PTR_CHAR 类别。字节字符的运算与索引均复用现有 u8 路径。

短路 &&/|| 建立 RHS、捷径、汇合块，以内部 bool local 保存选择的结果，汇合后 load；不通过提前计算 RHS 再选择值实现短路。所有普通操作数/实参仍先按源码从左到右降低。

## 前端与强制常量求值

先收集全部函数签名并检查重复定义，第二遍名称/类型检查与 IR 降低同时进行。块保存语句索引边，局部符号按作用域压栈、退出时恢复；同层重复拒绝，内层暂允许遮蔽。for 头部作用域覆盖条件、迭代项和循环体，体内声明不会泄漏给迭代项。

:= 初始化生成临时指令范围、结果位置和 AtriIRConstant 义务。禁止直接读取运行期局部/参数；不会因为优化器知道值而改变合法性。全部函数体都检查，包括不可达源码；所有常量义务均必须求值成功。

独立解释器支持八种定宽整数运算及 bool 存储、比较、整数转换、调用、递归、分支、循环及内部非指针局部存储。执行程序计数器选择实际后继，未选中的分支/RHS 不执行；执行到的未使用调用仍保留行为。每次循环重执行指令时刷新其缓存结果，不能沿用上一迭代的 load 或算术值。函数内显式常量初始化属于独立编译期义务，不重复作为运行期语句执行。

`#run` 在初始化器和独立语句中均复用常量义务与结果占位。顶层独立语句放入临时函数，完成求值后随临时函数删除。函数内独立 `void` 调用也生成求值义务，占位仅用于标记求值区间，没有对外可见的结果。已完成的 `#run` 区间从运行期 IR 清除，普通变量的初始化和后续写入仍遵循绑定语义。两类代码块均在解析时诊断尚未实现。

直接常量初始化中的 &&/|| 暂用私有 lazy_logical DAG 指令实现按需求值，避免把要删除的常量初始化范围扩展成运行期 CFG。普通运行期逻辑表达式降低为 CFG。`?:` 的运行期降低使用两条分支和一个结果 local，只执行选中分支。常量初始化用私有 lazy_select，left/right/callee 分别保存条件、true 值和 false 值引用，仅解释选中值。两条私有指令都必须在公开 IR 验证前删除。

`defer` 降低复用现有 CFG、CALL 和存储指令。降低器在每条作用域退出边按逆序展开已执行到的延迟体，循环和 switch 目标记录退出时所需的清理范围。条件清理生成普通分支。RETURN 使用清理前已求得的值，聚合 LOAD 继续提供值快照。延迟体按登记点的绑定链寻找原有存储位置。

求值缓存区分未访问/进行中/完成，检测常量依赖循环；全次编译限 100000 步、递归/依赖深度 256。失败编译报错，不能回退运行期。成功后结果写为 const，初始化范围标 NOP，释放义务。聚合值/内存、指针值、string、address、指针访存及算术仍不支持编译期执行；实际执行到外部 call 时在求值实参前报错，不执行宿主 C 函数。内部整数/bool local 不等于引入完整编译期地址模型。

## 整数枚举与 switch

AST 保存 enums/variants，模块符号表 kind 4 指向枚举命名空间；类型名解析为 underlying 整数，成员表达式解析为同类型 CONST。IR Program 拥有枚举名称/成员位模式元数据并在 destroy 释放；这些数据供 Dump/Verifier 使用，不成为目标程序的类型对象、标签或值域检查。字段、指针、数组、调用和算术只看原有整数 IRType，因此不会保留独立枚举身份。布局阶段检查成员命名/位模式重复、自动递增/左移容量以及位枚举非零单一位；Verifier 检查表范围、就绪状态、底层整数和成员位模式。显式初值目前复用布局整数表达式解释器，不调用完整函数解释器。

switch 不新增 IR 指令：选择表达式降低一次，case 通过现有标量常量义务生成稳定占位，随后顺序比较并 branch 到各分支；default 为最后的匹配失败目标。每个 case 体有独立词法绑定栈，非空体默认跳到 switch end，空体组和 #through 跳到源码下一分支。退出目标栈复用原循环目标结构，again == NONE 标记 switch；break 使用最近 stop，continue 忽略 switch 并向外寻找循环。分支中的不可达源码仍检查，case 常量义务不依赖优化。

全部常量求值后按 switch 源码位置和位模式排序检查重值，再释放临时索引；比较/分支/跳转仍由已有 Verifier、常量解释器、优化器与 x64 后端处理，所以编译期函数也可执行 switch。选择是 O(case 数) 比较链，代码/块和编译器临时数组按 case 数增长，重值排序 O(n log n)；没有运行期 case 函数调用或额外标签。首版未增加跳转表或多块存储消除，不以原生语义通过承诺分派性能最优。

#run/#extern/#through 的前缀区分发生在词法/解析阶段；不改变底层 IR 指令种类。#run 代码块仅定义能力并给出未实现诊断，不构造可执行块或占位降级；cast/sizeof/alignof 继续使用原运算符解析。

## 可达性与优化

完成常量求值后先验证所有 IR，包括不可达块的类型；依据常量 bool 分支计算可达性。可达路径若落入函数末尾的 unreachable，诊断缺少返回；没有可达出口的无限循环可以通过。不分析任意算术命题、变量归纳或循环必然终止，因此某些需要证明的返回路径仍保守拒绝。

然后删除可证明不可达块、把常量 branch 化为 jump，并更新块号；所有源码已在此前完成语义检查，不能靠不可达分支隐藏未知名称、错误类型或失败的 := 声明。

原有单块优化继续保留：

1. 直接值映射和已知值传播。
2. 折叠整数、bool 非及比较；整数采用已接受的 BD-06 语义。
3. -O1 克隆合适的小型单块叶函数，替换参数并继续折叠。
4. 逆序保留 return/call/store 及其依赖，删除无用纯计算。
5. 多轮内联处理短调用链，保留递归环保留的调用。

叶函数要求无 call/local/load/store、活跃指令至多 64、原始指令至多 4096；调用者增长有预算，最多 64 轮。含多块 CFG 的函数暂跳过这组优化，也不作为内联目标，避免把单块 DCE/折叠直接套到跳转图。-O0 保留调用，但仍进行单块折叠/DCE。尚无 mem2reg、phi、跨块传播/CSE、循环优化、复杂别名分析或寄存器分配。

后端在完整 IR 验证后筛选函数输出：有普通 main 定义时，以它为根沿剩余 call.callee 遍历，-O0/-O1 均只输出可达定义/外部声明；不可达递归环不会因互相引用而保留。没有 main 定义时保留全部函数，供外部调用。用标记数组和非递归工作队列，每个可达函数只扫描一次；新增分析耗时 O(F + I)，临时内存 O(F)，F 为函数数、I 为可达函数指令数，不增加目标程序的运行时成本。函数数组和 callee 编号不压紧，IR Dump 仍包含全部函数；字符串池本轮不压紧。正式导出、函数地址及回调实现时必须相应扩展保留根。

## Verifier

在降低完成、优化前后及输出前执行：

- 类型/常量位宽与合法表示、opaque 不能作为对象、void 不能作为普通值，临时常量义务必须清空，拒绝私有 lazy_logical/lazy_select。
- 块标签完整且唯一、跳转目标有效、每块终结、条件为 bool、返回类型正确。
- 操作数先定义、可达 CFG 上支配使用位置；不可达块仍检查操作数类型和索引。
- 参数编号/类型，调用目标及实参范围、数量、类型；variadic 固定前缀与提升后的尾参单独检查。
- 外部声明没有函数体；string 引用类型/索引正确，Program 字节数据包含额外的终止零。
- local/field/index 不当成值；address、load/store 内容与目标类型匹配；结构体布局、字段归属及快照类型正确。
- compare 的操作符/操作数匹配：整数可排序，bool/指针只相等比较，指针操作数的目标类型相同。
- ptr_offset 左指针、右 i32/i64 偏移、结果保持左指针类型；ptr_diff 两个同类型指针、结果 i64。两者目标必须完整且大小为正，void/opaque/零大小目标拒绝。

Verifier 负责内部结构；不提供借用、完整生命周期、动态空值或边界证明。

删除可证明不可达块后检查可求值的移位数量，使 -O0/-O1 都拒绝负数或数量达到位宽；私有 lazy 指令中的未执行表达式仍由常量解释器保持短路。每条移位的静态求值复用 100000 步/256 深度上限，不构成完整跨块常量传播；尚无跨指令求值缓存或编译性能承诺。内联/折叠发现指针常量偏移时，按真实元素布局复查缩放的 i64 范围，不再写死 1/4 字节步长。

## Windows x64 后端

IR 不绑定 EAX/RCX 等寄存器。后端先布局调用空间、局部对象及临时栈槽，再输出带函数内唯一标签的跳转；每个 return 恢复栈帧并 ret，合法程序中的 unreachable 不可达。

8/16/32/64 位整数对象分别使用 BYTE/WORD/DWORD/QWORD，u8/i8 字节使用 BYTE 并按各自类型解释。8/16 位结果截断后按类型符号/零扩展到 32 位临时槽，实际对象读写仍使用真实宽度；常量保持低位模式。bool 对象占 1 字节，临时值保持 0/1；参数和调用返回只读取对应 ABI 低位，不依赖未定义高位。

按有/无符号性选择除余、比较及右移；变量移位数量放入 CL，合法范围由语言契约约束，动态不插入范围检查。cast 复用规范化值执行必要扩展/截断；C_PROMOTE 把 i8/u8/i16/u16/bool 尾参提升为 i32，Verifier 不允许这些未提升类型留在可变尾部。默认不引入堆分配或检查运行时；栈槽/额外 mov 仍可能保留，不声称指令最少。

address 使用 lea；string 使用 RIP 相对地址引用只读数据。指针偏移先将 i32 扩展到 64 位，再按目标真实元素大小缩放；差值为有符号 64 位字节差除以元素步长。默认不检查同对象、整除、空值或溢出；整数环绕不能使非法指针操作合法。

调用保留 x64 shadow space、16 字节对齐、完整指针/64 位参数及栈参数；输出 .seh 元数据服务目标 ABI，语言无异常。暂限栈帧小于 4096 字节、每次调用至多 256 实参、每函数至多 4096 块。

extern(C) call 使用原始 C 名称并由链接器解析；普通定义仍使用现有 main/atri_fn_<索引> 映射。输出前检查外部名称与内部生成符号的冲突。稳定 ABI 方向与 C 一致，但当前临时内部符号不是稳定导出协议。

新增类型或指令必须同步修改定义、降低、解释器、Verifier、Dump、优化器、后端及行为测试。不能让新指令在某一阶段静默忽略。
