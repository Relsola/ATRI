# Stage 0 IR 内部设计 v0.1

> 当前实现契约，2026-11-16。不是语言语法标准；总体方向见[架构草案](self_hosting_compiler_design_v0_1.md)，实际范围见[基础编译原型](parser_subset_v0_1.md)。

## 表示与基本块

AtriIRProgram → AtriIRFunction → AtriIRInst[]，函数另有调用实参索引数组。函数索引引用调用目标，指令索引引用函数内定义；名称及原始源码区间用于 Dump/诊断和外部符号输出，输入源码必须保持存活。Program 另拥有 strings 数组及各项解码字节，length 不含额外终止零字节，destroy 时释放。

值类型为 i32、i64、bool、*i32、*char、名义结构体及结构体指针，函数签名记录所有参数及返回值。普通函数有显式 block_count，入口块 0 隐含存在，其余块用 label immediate 标识；物理排列顺序不必等于块号顺序。jump、branch、return、unreachable 为终结指令，每块必须恰有一个终结，不能隐式落入后继块。branch 的条件必须为 bool，分别记录真/假目标。

external_c 函数只记录签名，instruction_count、argument_count 和 block_count 必须为 0，不生成函数体、栈帧、CFG 或展开信息。call 继续通过函数索引统一引用普通定义和外部声明。extern(C) 不进入内联或常量解释执行。

param、const、unary、binary、compare、call、load、address、ptr_offset、ptr_diff、string、zero 产生值。string.type 必须为 *char，immediate 是 Program.strings 的稳定索引，不是宿主或目标地址，优化/内联复制指令时保留此索引。local 是内部存储对象，store/控制指令不产生值；NOP 标记删除的指令。值必须先定义再使用，在可达 CFG 上定义块必须支配使用块。本轮不引入 phi；跨分支/回边的可变状态由显式局部存储表达。

整数常量用 uint64_t 保存位模式，i32 高 32 位必须为 0；有符号解释不依赖宿主 C 溢出。bool 常量仅允许 0/1。指针 const 只表示 null，不能借常量字段伪造非空宿主地址。

## 模块与全局存储

AST 保留 import、export、全局声明与模块文件区间；名称表绑定到原函数/全局 ID。IR 函数保存 module ID，仅根模块的 main 使用入口符号。Program.globals 保存全局类型、初始位模式及编译期常量标记。共享全局不按导入次数复制，编译期常量引用折叠后不输出独立数据对象。

LOCAL.immediate 为 0 时表示原栈对象，非零时表示 globals 索引 + 1 的全局存储位置。LOAD/STORE/ADDRESS 继续引用该稳定位置；Verifier 检查索引、类型及不写编译期常量。后端对全局位置使用 RIP 相对寻址，不分配栈对象，不插入锁或原子操作。优化器保留 STORE 和相关存储位置，含访存函数不作为叶函数内联目标。常量解释器拒绝读取/写入运行期全局，不执行宿主全局访问。

全局初始化暂以临时函数及常量义务使用现有解释器求值；求值后提取初始位模式、替换全局编译期常量引用并删除临时函数。它们不进入最终调用图，不产生隐式运行期初始化函数。指针静态初始值当前仅为 null，静态重定位初始化尚未实现。

## 结构体布局、值与调用

Program.structs/fields 保存名义类型、字段类型、偏移、大小/对齐和标量默认值；动态结构体类型 ID 与其指针 ID 分区编码，Verifier 检查索引有效性。模块名称表包含结构体声明身份。AST 记录字段默认表达式、指定初始化项及 FIELD 表达式；字段默认值借用独立常量求值，临时函数及调用在运行期 IR 前删除，不生成隐藏的运行期默认值函数。

ZERO 产生结构体零值快照；FIELD 为存储位置（不是普通值），left 引用原对象位置、结构体值快照或显式解引用后的结构体指针，immediate 为 fields 的稳定索引。LOAD/STORE 可复制完整结构体，ADDRESS 可取得 i32 或结构体位置的指针。局部结构体有稳定存储；字段读写定位原对象，值传参和赋值则取得快照。Verifier 检查字段所属名义类型、自然布局、内容类型、支配关系和地址目标。

Windows x64 后端为结构体对象/快照分配自然布局的栈空间，间接调用实参副本按 16 字节对齐；复制使用易失寄存器和定长分块 mov，不引入运行期堆分配。1/2/4/8 字节结构体走整数寄存器/栈槽，其余正大小结构体走独立副本指针，返回使用隐藏首参及 RAX 缓冲区地址。调用区按最大参数及副本需求复用，隐藏返回地址单独保存，普通参数的位置计入隐藏首参。空结构体当前内部采用零内容、单实参位置约定，C 按值接口拒绝零大小结构体。

含结构体、结构体指针或 FIELD 的函数暂跳过旧单块优化/内联，防止错误重映射对象和快照；尚无聚合复制消除或标量替换。结构体 :=、结构体全局和聚合默认表达式继续诊断为未支持，常量解释器不把结构体临时存储当作宿主地址执行。

## 局部对象与访存

local.type 是对象内容类型，可含结构体；local/field 位置不能作为普通值或指针传给函数。address 取得 i32 或结构体位置的地址；load/store 的目标可为内容类型匹配的位置或目标类型匹配的 i32/结构体指针。*char local 只存储指针值，不支持通过 *char 访问 char 标量。store 没有结果值。

含控制流或运行期短路表达式的函数，普通可变变量使用 local/load/store；参数仍是只读值，编译期常量保留结果值。直线函数中，未取地址变量保留已有值映射，赋值更新映射；被取地址 i32 变量使用稳定对象，直接名称与指针访问均观察同一存储。取地址预扫描保守按名称匹配，可能多分配对象，不做逃逸优化。

短路 &&/|| 建立 RHS、捷径、汇合块，以内部 bool local 保存选择的结果，汇合后 load；不通过提前计算 RHS 再选择值实现短路。所有普通操作数/实参仍先按源码从左到右降低。

## 前端与强制常量求值

先收集全部函数签名并检查重复定义，第二遍名称/类型检查与 IR 降低同时进行。块保存语句索引边，局部符号按作用域压栈、退出时恢复；同层重复拒绝，内层暂允许遮蔽。for 头部作用域覆盖条件、迭代项和循环体，体内声明不会泄漏给迭代项。

:= 初始化生成临时指令范围、结果位置和 AtriIRConstant 义务。禁止直接读取运行期局部/参数；不会因为优化器知道值而改变合法性。全部函数体都检查，包括不可达源码；所有常量义务均必须求值成功。

独立解释器支持 i32/i64/bool 运算、比较、调用、递归、分支、循环及内部非指针局部存储。执行程序计数器选择实际后继，未选中的分支/RHS 不执行；执行到的未使用调用仍保留行为。每次循环重执行指令时刷新其缓存结果，不能沿用上一迭代的 load 或算术值。函数内显式常量初始化属于独立编译期义务，不重复作为运行期语句执行。

直接常量初始化中的 &&/|| 暂用私有 lazy_logical DAG 指令实现按需求值，避免把要删除的常量初始化范围扩展成运行期 CFG。它会随初始化范围删除，不能进入公开 IR；普通运行期逻辑表达式一律降低成 CFG。

求值缓存区分未访问/进行中/完成，检测常量依赖循环；全次编译限 100000 步、递归/依赖深度 256。失败编译报错，不能回退运行期。成功后结果写为 const，初始化范围标 NOP，释放义务。指针值、string、address、指针访存及算术仍不支持编译期执行；实际执行到外部 call 时在求值实参前报错，不执行宿主 C 函数。内部整数/bool local 不等于引入完整编译期地址模型。

## 可达性与优化

完成常量求值后先验证所有 IR，包括不可达块的类型；依据常量 bool 分支计算可达性。可达路径若落入函数末尾的 unreachable，诊断缺少返回；没有可达出口的无限循环可以通过。不分析任意算术命题、变量归纳或循环必然终止，因此某些需要证明的返回路径仍保守拒绝。

然后删除可证明不可达块、把常量 branch 化为 jump，并更新块号；所有源码已在此前完成语义检查，不能靠不可达分支隐藏未知名称、错误类型或失败的 := 声明。

原有单块优化继续保留：

1. 直接值映射和已知值传播。
2. 折叠整数、bool 非及比较；整数采用暂用的 BD-06 候选语义。
3. -O1 克隆合适的小型单块叶函数，替换参数并继续折叠。
4. 逆序保留 return/call/store 及其依赖，删除无用纯计算。
5. 多轮内联处理短调用链，保留递归环保留的调用。

叶函数要求无 call/local/load/store、活跃指令至多 64、原始指令至多 4096；调用者增长有预算，最多 64 轮。含多块 CFG 的函数暂跳过这组优化，也不作为内联目标，避免把单块 DCE/折叠直接套到跳转图。-O0 保留调用，但仍进行单块折叠/DCE。尚无 mem2reg、phi、跨块传播/CSE、循环优化、复杂别名分析或寄存器分配。

后端在完整 IR 验证后筛选函数输出：有普通 main 定义时，以它为根沿剩余 call.callee 遍历，-O0/-O1 均只输出可达定义/外部声明；不可达递归环不会因互相引用而保留。没有 main 定义时保留全部函数，供外部调用。用标记数组和非递归工作队列，每个可达函数只扫描一次；新增分析耗时 O(F + I)，临时内存 O(F)，F 为函数数、I 为可达函数指令数，不增加目标程序的运行时成本。函数数组和 callee 编号不压紧，IR Dump 仍包含全部函数；字符串池本轮不压紧。正式导出、函数地址及回调实现时必须相应扩展保留根。

## Verifier

在降低完成、优化前后及输出前执行：

- 类型/常量位宽与合法表示，临时常量义务必须清空，拒绝私有 lazy_logical。
- 块标签完整且唯一、跳转目标有效、每块终结、条件为 bool、返回类型正确。
- 操作数先定义、可达 CFG 上支配使用位置；不可达块仍检查操作数类型和索引。
- 参数编号/类型，调用目标及实参范围、数量、类型。
- 外部声明没有函数体；string 引用类型/索引正确，Program 字节数据包含额外的终止零。
- local/field 不当成值；address、load/store 内容与目标类型匹配；结构体布局、字段归属及快照类型正确。
- compare 的操作符/操作数匹配：整数可排序，bool/指针只相等比较，指针操作数的目标类型相同。
- ptr_offset 左指针、右 i32/i64 偏移、结果保持左指针类型；ptr_diff 两个同类型指针、结果 i64。

Verifier 负责内部结构；不提供借用、完整生命周期、动态空值或边界证明。

## Windows x64 后端

IR 不绑定 EAX/RCX 等寄存器。后端先布局调用空间、局部对象及临时栈槽，再输出带函数内唯一标签的跳转；每个 return 恢复栈帧并 ret，合法程序中的 unreachable 不可达。

i32 内容使用 DWORD，i64/指针使用 QWORD；bool 对象占 1 字节，临时值占 4 字节并保持 0/1，传入 bool 从参数低字节读取，调用返回 bool 从 AL 零扩展。比较用 cmp/setcc，! 对规范化 bool 取反。address 用 lea 形成局部地址；string 用 RIP 相对 lea 引用 .rdata 中的只读字节，两者均不分配临时指针栈槽或运行期堆内存。其他临时值暂存栈，不承诺当前生成代码已经无额外访存。

指针偏移先将 i32 movsxd 为 64 位，再按 i32/char 的 4/1 字节步长缩放；差值使用有符号 64 位字节差除以元素步长。默认不检查同对象、整除、空值或溢出。普通整数环绕不能使非法指针算术合法。

调用保留 x64 shadow space、16 字节对齐、完整指针/64 位参数及栈参数；输出 .seh 元数据服务目标 ABI，语言无异常。暂限栈帧小于 4096 字节、每次调用至多 256 实参、每函数至多 4096 块。

extern(C) call 使用原始 C 名称并由链接器解析；普通定义仍使用现有 main/atri_fn_<索引> 映射。输出前检查外部名称与内部生成符号的冲突。稳定 ABI 方向与 C 一致，但当前临时内部符号不是稳定导出协议。

新增类型或指令必须同步修改定义、降低、解释器、Verifier、Dump、优化器、后端及行为测试。不能让新指令在某一阶段静默忽略。
