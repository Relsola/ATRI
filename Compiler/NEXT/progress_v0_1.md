# Stage 0 进度记录 v0.1

> 更新：2026-11-16。本版应用户要求整理并提交；语言规范仍在迭代，后续修改继续默认本地保存，提交与推送分别按用户指令执行。

## 本版提交汇总

相对上次提交 `738c757`，本版整合此前积累的本地修改：

- 声明去掉 let/const，普通变量采用 `name: Type [= expression]`，唯一显式编译期常量采用 `name: Type := expression`；新增独立常量解释器，求值失败不回退运行期。
- 实现 i64、整数指针取地址/显式解引用、null、按元素加减和 i64 差值，并贯通类型检查、优化、Windows x64 参数/返回及原生测试。
- 实现已接受的 BD-19 控制流、bool/比较/短路、多块 CFG 和支配验证，常量函数支持分支、循环与终止递归；同步规范、实现边界、示例和五组测试。

本版仍未实现 defer、结构体/数组、模块、外部调用及完整 run/AST 系统；BD-06 等候选规则继续保留待审查状态。

## 已实现

当前链路：源码 → Lexer/Parser/AST → 名称/类型检查 → 强制编译期常量求值 → 多块 Typed IR → 优化 → Windows x64 汇编；Clang 负责汇编/链接。

| 部分 | 当前范围 |
|---|---|
| 声明 | fn name(args) -> Type；参数/变量 name: Type；:= 编译期常量 |
| 名称 | 先收集全部函数签名，后定义可调用；块作用域、同层重复拒绝、内层遮蔽候选 |
| 局部变量 | 普通变量可变、默认零初始化；参数只读候选，常量必须编译期成功 |
| 值与表达式 | i32、i64、bool、*i32；整数算术、比较、bool 逻辑与短路 |
| 指针 | 一层 *i32、&、显式 * 读写、null、复制/参数/返回、元素偏移/差值、==/!= |
| 控制流 | if/else if/else、while、do...while、for、loop、break/continue、return；所有体强制 {} |
| 编译期求值 | 整数/bool、函数调用/递归、分支/循环、内部可变局部；错误/依赖循环/资源限制诊断 |
| IR | 多基本块、显式跳转、条件分支、比较、局部对象/load/store/address、调用与 Verifier |
| 优化 | 直线函数传播/折叠/DCE/叶函数内联；常量 bool 分支不可达块删除 |
| 后端 | Windows x64 参数/返回/调用、栈帧、跳转、比较、展开描述 |
| 工具 | C23/CMake/Ninja；atri-parse 与 atri-cc，AST/IR/汇编输出 |

[main.txt](../examples/main.txt)、[constants.txt](../examples/constants.txt)、[pointers.txt](../examples/pointers.txt)、[pointer_arithmetic.txt](../examples/pointer_arithmetic.txt)、[control_flow.txt](../examples/control_flow.txt) 均可生成本机可执行程序，退出码为 3。常量示例在 -O0 下也直接返回 3；控制流示例同时包含循环、短路和强制求值的递归阶乘。

实现范围、限制和命令见[基础编译原型](parser_subset_v0_1.md)、[整数指针子集](pointer_subset_v0_1.md)及 [IR 设计](ir_design_v0_1.md)。

## 设计状态

已接受 BD-19，当前已实现其条件、循环与退出行为。bool 条件没有指针例外；p != null 才是显式非空检查，不保证地址有效。所有控制体和 defer 体必须用 {}；defer 的词法退出、逆序、执行时读取当前值已接受，语言无异常，defer 本身尚未实现。

保留 DOP、零隐藏运行时/分配方向、变量默认零初始化、:= 强制常量、结构体指定字段及重复字段报错、(*p).field 显式解引用、顶层函数无需前向声明。数组已选择 C 布局及有限静态检查；BD-16 自然布局接受，空结构体大小 0、对齐 1。聚合相关规则尚未进入实现。

整数规则暂用 BD-06 候选；求值顺序/短路、bool 布局、参数只读/遮蔽和 for 头部详细范围按当前候选落地，均未自动冻结其他提案。正式状态以[规范](language_spec_v0_1.md)和[审查稿](language_defaults_review_v0_1.md)为准。

## 验证

Windows x86-64、Clang 23.1.2、C23、Ninja，构建警告作为错误。CTest 五组全部通过：

1. 前端：AST、优先级、实参、源码位置、BOM/换行、非法输入、扩容与深度限制。
2. 编译器回归：整数边界、名称/类型、常量及失败/循环/深度限制、调用/内联、指针及 IR 不变量。
3. 控制流：必需花括号、bool 类型、作用域、for 可见性、返回路径、循环外退出错误、短路常量、循环与递归求值、无限循环预算，以及 CFG 跳转/支配验证。
4. 示例：CLI 解析 main.txt。
5. 原生：-O0/-O1 下生成汇编、链接、执行全部示例；C 驱动验证整数环绕/负数除余、六参数与别名、64 位指针/偏移/差值，以及所有循环、嵌套 break、continue 目标、短路副作用、指针遍历、六个 bool 参数、i64 比较/局部存储与终止递归。

这些验证不代表全部语言提案已实现。

## 后续

- 尚未实现 defer、match、聚合/数组、多层/其他目标指针、指针转换、模块、外部函数、run/AST 修改 API；浮点按用户要求暂缓。
- 编译期不支持指针值/地址访问，内部整数/bool local 不等于完整编译期内存模型。
- 多块函数暂不实施跨块传播、DCE/内联、循环优化或寄存器分配；必要语义操作外仍有原型栈槽开销。目标限制见子集文档。
- M0 的控制流纵向链路已打通；结构体和基本 C 外部调用等完整验收仍未完成。
