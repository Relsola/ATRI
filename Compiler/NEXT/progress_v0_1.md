# Stage 0 进度记录 v0.1

> 更新：2026-11-17。本轮增量按用户要求整理提交，既有提交汇总保留为历史；语言规范仍在迭代，后续修改继续默认本地保存，提交与推送分别按用户指令执行。

## 本次增量：固定数组与标量 run（2026-11-17，本地工作区）

已实现 `data: [N]u8 = {1, 2};`、u8/*u8、固定/多维/字段数组、按值复制/传参/返回、索引读写及静态越界诊断。数组长度支持可见整数常量和基本整数算术，尚不支持布局期间的函数调用。当前缺省元素、类型身份和复制细节属于原型行为，未自动冻结全部 BD-12/15；准确边界见[实现子集](parser_subset_v0_1.md#固定数组的当前实现)。

用户澄清 run 为编译期执行；已实现顶层/局部 `run name: Type := expression;` 和整数/bool run 表达式，补齐 max 示例使用的短路三元条件表达式。复用独立常量解释器，求值失败必须报错，-O0 也不回退运行期。run 代码块、聚合编译期内存与 AST API 仍未实现，完整自举路线未在本轮变更。

本轮 Debug 构建零警告，CTest 七组通过，新增 Windows 原生 -O0/-O1 用例覆盖数组值/地址行为、初始化顺序、字节运算、u8 固定签名 C 调用及内嵌数组结构体的双向 ABI。run_constants 示例两种等级下均只生成 main，直接返回 2。新增原生用例曾返回 4，根因是元素地址计算覆盖了地址寄存器；索引改为在执行点保存地址后通过回归。新增编译失败用例及 Verifier 用例单独核对诊断和错误 IR。未进行性能测量，也未证明复制最少；当前额外快照、复制和索引地址栈槽仍有成本。本轮修改仅本地保存，未暂存/提交/推送。

以下模块/结构体及旧阶段记录保留为历史，不代表完整语言、自举或本轮全部新增功能的验收范围。

## 本次增量：模块与结构体（2026-11-17）

已贯通模块导入、类型/函数/标量全局导出和共享全局对象。新增结构体名义类型、自然布局、字段默认值和指定初始化、字段/嵌套读写、复制、参数/返回与结构体指针。当前准确边界见[实现子集](parser_subset_v0_1.md#结构体的当前实现)，验证入口见[测试说明](../tests/README.md#结构体回归)。结构体全局、:= 聚合常量及聚合复制消除尚未实现；不将 ABI 测试通过当作性能测量。以下提交汇总与旧阶段记录不代表本轮新增验证。

## 本次增量：C 字符串与 puts

按用户确认，字符指针与 C 一致，内置 string 整体暂缓，稳定 ABI 目标与目标 C 一致。已实现 `[[extern(C)]]` 固定签名声明、静态零结尾字符串字面量、`*char` 值与字节偏移，以及通过 C 运行库调用 puts；这些改动与模块、结构体实现一并整理提交。

新增 [hello.ar](../examples/hello.ar)、[c_strings.ar](../tests/cases/c_strings.ar) 和 [C ABI 驱动](../tests/c_abi_harness.c)。本轮构建零警告，前端/编译器/控制流/优化/Verifier/示例检查通过，Windows 原生测试在 -O0/-O1 下核对了真实 stdout、UTF-8 字节、内嵌零截断、寄存器与栈参数、64 位值、C 指针/bool 返回和外部内存写入。该证据不包含性能测量或完整 C ABI 验收。

字面量不引入运行期堆分配，但仍占静态数据，puts 扫描、CRT 缓冲和实际 I/O 有成本。外部声明只保留签名与符号，优化和常量求值不会执行外部代码；该阶段尚不支持 char 标量、void、浮点、可变参数、聚合按值 ABI、回调和正式导出；结构体的当前支持范围见上文。确定规则见[语言规范第 5.5/13 节](language_spec_v0_1.md#13-c-互操作与执行环境)，实际边界见[实现子集](parser_subset_v0_1.md#c-字符串与外部调用)。

## 本版提交汇总

相对上次提交 `738c757`，本版整合此前积累的本地修改：

- 声明去掉 let/const，普通变量采用 `name: Type [= expression]`，唯一显式编译期常量采用 `name: Type := expression`；新增独立常量解释器，求值失败不回退运行期。
- 实现 i64、整数指针取地址/显式解引用、null、按元素加减和 i64 差值，并贯通类型检查、优化、Windows x64 参数/返回及原生测试。
- 实现已接受的 BD-19 控制流、bool/比较/短路、多块 CFG 和支配验证，常量函数支持分支、循环与终止递归；同步规范、实现边界、示例和五组测试。

本版仍未实现 defer、结构体/数组、模块、完整 C ABI 及完整 run/AST 系统；BD-06 等候选规则继续保留待审查状态。

## 已实现

当前链路：源码 → Lexer/Parser/AST → 名称/类型检查 → 强制编译期常量求值 → 多块 Typed IR → 优化 → Windows x64 汇编；Clang 负责汇编/链接。

| 部分 | 当前范围 |
|---|---|
| 声明 | fn name(args) -> Type；参数/变量 name: Type；:= 编译期常量 |
| 名称 | 先收集全部函数签名，后定义可调用；块作用域、同层重复拒绝、内层遮蔽候选 |
| 局部变量 | 普通变量可变、默认零初始化；参数只读候选，常量必须编译期成功 |
| 值与表达式 | i32、i64、bool、*i32、*char；整数算术、比较、bool 逻辑与短路 |
| 指针 | 一层 *i32/*char、null、复制/参数/返回、元素偏移/差值、==/!=；& 与显式目标读写仍限 i32 |
| C 调用与文本 | [[extern(C)]] 完整固定签名、原始 C 名称、静态字面量、puts 标准输出 |
| 控制流 | if/else if/else、while、do...while、for、loop、break/continue、return；所有体强制 {} |
| 编译期求值 | 整数/bool、函数调用/递归、分支/循环、内部可变局部；错误/依赖循环/资源限制诊断 |
| IR | 多基本块、显式跳转、条件分支、比较、局部对象/load/store/address、调用与 Verifier |
| 优化 | 直线函数传播/折叠/DCE/叶函数内联；常量 bool 分支不可达块删除 |
| 后端 | Windows x64 参数/返回/调用、栈帧、跳转、比较、展开描述 |
| 工具 | C23/CMake/Ninja；atri-parse 与 atri-cc，AST/IR/汇编输出 |

[main.ar](../examples/main.ar)、[constants.ar](../examples/constants.ar)、[pointers.ar](../examples/pointers.ar)、[pointer_arithmetic.ar](../examples/pointer_arithmetic.ar)、[control_flow.ar](../examples/control_flow.ar) 均可生成本机可执行程序，退出码为 3。常量示例在 -O0 下也直接返回 3；控制流示例同时包含循环、短路和强制求值的递归阶乘。

实现范围、限制和命令见[基础编译原型](parser_subset_v0_1.md)、[整数指针子集](pointer_subset_v0_1.md)及 [IR 设计](ir_design_v0_1.md)。

## 设计状态

已接受 BD-19，当前已实现其条件、循环与退出行为。bool 条件没有指针例外；p != null 才是显式非空检查，不保证地址有效。所有控制体和 defer 体必须用 {}；defer 的词法退出、逆序、执行时读取当前值已接受，语言无异常，defer 本身尚未实现。

保留 DOP、零隐藏运行时/分配方向、变量默认零初始化、:= 强制常量、结构体指定字段及重复字段报错、(*p).field 显式解引用、顶层函数无需前向声明。数组已选择 C 布局及有限静态检查；BD-16 自然布局接受，空结构体大小 0、对齐 1。聚合相关规则尚未进入实现。

整数规则暂用 BD-06 候选；求值顺序/短路、bool 布局、参数只读/遮蔽和 for 头部详细范围按当前候选落地，均未自动冻结其他提案。正式状态以[规范](language_spec_v0_1.md)和[审查稿](language_defaults_review_v0_1.md)为准。

## 验证

Windows x86-64、Clang 23.1.2、C23、Ninja，构建警告作为错误。CTest 七组全部通过：

1. 前端：AST、优先级、实参、源码位置、BOM/换行、非法输入、扩容与深度限制。
2. 编译器回归：整数边界、名称/类型、常量及失败/循环/深度限制、指针类型。
3. 控制流：必需花括号、bool 类型、作用域、返回路径、错误退出、短路常量、循环/递归求值和资源预算。
4. 优化效果：按函数名检查优化前后调用、常量返回、无用计算消除及副作用/递归调用保留，不依赖指令固定下标。
5. IR Verifier：单独构造错误值、终结指令、访存类型、跳转目标、支配关系及函数签名。
6. 示例：CLI 解析 main.ar。
7. 原生：-O0/-O1 下汇编、链接并执行全部示例、优化用例及 C 驱动；验证整数、指针、调用约定和各类控制流，新增 puts 实际 stdout 与 C 外部调用。C 驱动使用源码函数名及期望/实际断言，普通定义的测试符号映射自动生成。

这些验证不代表全部语言提案已实现。

## 后续
