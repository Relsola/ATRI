# 指针实现子集 v0.1

> 当前 Stage 0 实现边界，2026-11-17。语言规则入口为[语言规范](language_spec_v0_1.md)，整体构建说明见[整数编译原型](parser_subset_v0_1.md)。当前新增结构体指针 *T；结构体字段、按值快照及调用边界统一见[结构体实现](parser_subset_v0_1.md#结构体的当前实现)，数组和浮点指针仍未实现。

## 用法

“引用”采用取地址运算，不增加独立的引用类型。指针类型前置 `*`，表达式使用 `&` 取地址、`*` 显式解引用：

```text
fn main() -> i32 {
    a: i32 = 1;
    p: *i32 = &a;
    *p = *p + 2;
    return a;
}
```

此例见 [pointers.ar](../examples/pointers.ar)，在 -O0/-O1 下均已汇编、链接并运行，退出码为 3。`*p` 可用于读值和赋值目标；`(*p) = value` 也可解析。解引用结果是对原对象的访问，不是先复制对象再修改副本。

支持指针赋值、复制、作为参数及返回值；参数绑定本身沿用当前不可重新赋值的候选，但通过指针参数写目标是允许的：

```text
fn write(p: *i32, value: i32) -> i32 {
    *p = value;
    return *p;
}

fn identity(p: *i32) -> *i32 {
    return p;
}
```

地址可以经由多个指针访问同一对象，所有读写必须观察实际内存修改。`&*p` 形成同一地址，不生成目标读取；它本身也不验证地址是否可访问。

## 类型与诊断

- 当前值类型包含 i32、i64、bool、一层 `*i32` 和 `*char`；星号与类型名之间允许普通空白。`**i32`、`**char`、`*i64` 和其他目标类型暂不支持。
- 指针值是 Windows x64 的 64 位地址；i32 元素大小为 4 字节，char 元素为 1 字节。指针类型不代表将目标内容扩宽为 64 位。
- `&` 当前接受普通可变 i32 局部变量，或显式解引用得到的 i32 对象。不接受常量、临时数值或只读参数的地址；需要参数副本时先声明普通变量。
- 取指针变量本身的地址会需要 `**i32`，本轮诊断为未支持；不以错误的 `*i32` 类型替代。
- i32、i64、`*i32` 与 `*char` 不隐式转换。普通整数 0 不能初始化指针；指针不能传给整数参数。下面规定的指针加减是独立的运算符类型规则，不是把指针隐式转为整数。
- `null` 已作为保留关键字实现，按 `*i32`、`*char` 或结构体指针上下文定型。未显式初始化的指针变量默认得到 null。这些指针都支持同类型的 ==/!=，可写 if (p != null) { ... }；不允许 if (p) 或 !p，也不提供指针排序比较。
- 在降低阶段能直接确定为空的解引用读写会诊断；不承诺通过任意函数或别名追踪所有空指针。
- 直接返回本函数局部对象的地址会诊断；尚无完整的借用、生命周期或逃逸分析。通过间接调用等复杂路径逃逸的地址仍可能悬空，不能据此声称内存安全。

所有地址必须指向仍存活、可访问并具有正确类型/对齐的对象。动态指针访问不插入空值、生命周期或边界检查，也不隐式分配、释放或生成语言异常。非法访问的完整语言分类仍按 BD-14/25 审查，不将 CPU 恰好产生的异常作为语言保证。

## 字符指针

`*char` 作为 C 兼容的单地址字符指针，支持复制、参数/返回、null、比较和字节偏移/差值。当前没有 char 标量，因此不接受字符解引用读写、char 局部对象或其取地址；主规范中的 char 目标表示/默认有符号性不代表已实现标量功能。静态字符串字面量可直接传给 puts，也可以由函数返回。[语言规范第 5.5 节](language_spec_v0_1.md#55-字符与字符串)集中维护布局、null/NUL/空串、编码、零结尾、权限与寿命，第 13.1 节说明 `char *` / `const char *` 等 C 原型的映射边界；实际示例见 [hello.ar](../examples/hello.ar)。

## 指针算术

```text
q: *i32 = p + 1;
r: *i32 = 2 + p;
s: *i32 = p - 1;
distance: i64 = q - p;
value: i32 = *(p + 1);
*(p + 1) = value + 1;
```

上述 p 必须具有相应连续存储的访问权限。支持 `pointer + integer`、`integer + pointer`、`pointer - integer` 和 `pointer - pointer`；不支持两个指针相加、整数减指针或指针乘除。偏移可为 i32 或 i64，单位是 i32 元素，即 1 对应 4 字节。i32 偏移先有符号扩展至 64 位再缩放，不先执行可能环绕的 i32 乘法；无其他类型上下文的偏移字面量按 i64 检查。

同一对象或连续元素存储内的指针差值返回 i64，单位也是元素，不是字节。指针运算只允许在同一存储内移动或形成尾后地址；尾后地址可以退回，但不能解引用。差值要求来自同一存储、字节距离可被 4 整除且相关地址/有符号距离计算可表示。地址/缩放溢出不采用普通整数环绕规则补救。当前只对部分可直接证明的空值和常量缩放溢出报错，不插入动态边界、同对象、整除或溢出检查；运行期非法操作不保证结果或陷阱。

`*char` 的同类算术沿用以上同对象/边界契约，元素步长为 1 字节，差值返回字节距离；两个指针必须具有相同目标类型。i32 偏移同样先符号扩展为 64 位。

`n + p` 仍按源码先计算 n，再计算 p，规范化 IR 的操作数位置不改变求值顺序。目前未加入 `+=`、`-=`、`++`、`--` 或指针排序，可写 `p = p + 1;`。原始指针完整内存契约继续按 BD-14/25 审查。

本语言数组尚未进入实现，原生测试用 C 数组提供合法连续存储，不依赖两个独立局部变量恰好相邻。[pointer_arithmetic.ar](../examples/pointer_arithmetic.ar) 则只使用单个整数的尾后地址及退回访问，-O0/-O1 退出码均为 3。

## 与编译期常量的边界

编译期常量仍使用 `name: Type := expression`。本轮不实现编译期指针值或指针访存；`p: *i32 := ...`、常量求值中调用实际执行指针值、取地址或指针访存的函数会明确报错，不回退到运行期。

若需要整数常量对应的可写对象，可以显式创建普通变量：

```text
n: i32 := 2;
a: i32 = n;
p: *i32 = &a;
```

整数/指针转换、函数指针、指针排序、多层指针、堆分配和编译期地址模型均不在本轮实现范围内，指针算术也不能在强制常量求值中执行。

## IR、优化与后端

IR 增加 `*i32` 类型，以及 local、load、store。被取地址的普通 i32 变量分配独立局部存储，后续直接变量访问也降低成 load/store；直线函数中未被取地址的变量继续使用已有值映射；控制流函数的普通变量通过内部局部存储衔接各分支和回边。local 记录内容类型，address 指令显式取得 i32 local 的地址。原型保守扫描当前函数的取地址语法，不做复杂逃逸优化。

store 和 call 为不能随意删除的副作用根。优化器不跨访存传播旧值；含局部存储或访存的函数暂不内联，避免未经设计就改变局部对象寿命与内存行为。纯值函数的现有传播/折叠/内联保留。

后端对 i32 使用 DWORD，对指针值使用 QWORD；local 的地址通过 lea 生成。参数、返回值、栈槽以及第五个及以后的参数均区分 32 位整数与 64 位指针，并保留既有调用空间、对齐和栈展开描述。

ptr_offset/ptr_diff 指令记录指针加减及差值，元素步长由目标类型确定：i32 为 4 字节，char 为 1 字节。i64 值和指针使用 64 位寄存器与 QWORD 栈槽；差值以 64 位字节差除以元素步长，合法负差值保留符号。纯指针算术函数可以内联，访存函数仍保守保留调用。

## 验证

CTest 五组覆盖原有整数/常量回归，以及新增的前端类型区间与运算符结合、类型不匹配、非法取地址/赋值、直接空指针访问、直接局部地址返回、IR 访存类型检查。

原生测试在 -O0/-O1 下运行指针示例，并用 C 调用生成函数验证：间接读写、相同/不同指针的别名行为、变量名与指针交替修改、指针传参与返回、混合六参数且第五个参数为指针、调用后重读内存，以及未使用调用结果时仍保留写入副作用。

新增 C 数组测试覆盖正负 i32/i64 偏移、整数加指针、指针减负数、尾后地址及退回、正负/零元素差值、偏移后的读写、内联算术函数，以及两侧调用的求值顺序。另验证 i64 运算/环绕/常量求值和含 i64 栈参数的混合调用。

```powershell
cmake --build build
ctest --test-dir build --output-on-failure
.\build\atri-cc.exe --emit-ir-before-opt .\examples\pointers.ar
.\build\atri-cc.exe -S -o .\build\pointers.s .\examples\pointers.ar
clang .\build\pointers.s -o .\build\pointers.exe
.\build\pointers.exe
$LASTEXITCODE # 3
```

控制流本机用例还覆盖 p != end 的数组遍历、p != null && *p > 0 的短路判空，以及分支内经指针和原变量交替写入的可见性。
