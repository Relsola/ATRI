# Compiler

Compiler 是 ATRI 大型个人项目的基础子项目，也是当前建设的第一步，目标是实现一门偏底层的强类型语言及可持续自举的原生编译器。

首个目标平台为 Windows x86-64，计划使用 C23 编写 Stage 0。当前处于语言规范与架构设计阶段，尚未开始编译器实现。

## 下一轮规范讨论

优先完善语言规范的 TYPE-01、TYPE-02、TYPE-03 与 MEM-01/MEM-02：

1. 确定核心类型清单、字面量的上下文定型与无上下文默认类型。
2. 明确 `let/const`、初始化、绑定和对象可变性之间的关系。
3. 确定整数转换和数值边界，保证编译期解释器与运行期后端遵循同一规则。
4. 用函数、Token/AST 数据结构和缓冲区示例检查这些规则是否足以支撑编译器开发。

每轮讨论形成合法示例、非法示例与预期结果，再更新规范中的规则状态。完整核心子集范围、Comptime 调度、模块剩余边界和目标 ABI 继续按规范决策清单推进，不在本说明中另行定义。
