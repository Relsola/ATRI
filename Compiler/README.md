# Compiler

Compiler 是 ATRI 大型个人项目的基础子项目，也是当前建设的第一步，目标是实现一门偏底层的强类型语言及可持续自举的原生编译器。

首个目标平台为 Windows x86-64，计划使用 C23 编写 Stage 0。当前处于语言规范与架构设计阶段，尚未开始编译器实现。

## 当前审查重点

已按用户授权拟定基础默认行为，新增方案仍待审查，用户可按 BD 编号指定修改。运行时零开销是明确方向，默认无隐式分配、强制语言运行时和动态检查；默认零初始化等必要语义成本仍需保留。

1. 整数环绕、cast 截断与非法运算边界（BD-06/07/25）。
2. char 编码单元、只读字符指针及暂不内置拥有型 string（BD-04/05/13）。
3. 对象 const、只读目标和按值复制（BD-10/11/12）。
4. 无默认内存检查、枚举有效零值及全局初始化限制（BD-14/15/17/24）。

主规范仍为规则维护入口，审查稿用于提出未确认行为和解释取舍；接受后再合入主规范。完整核心子集范围、AST 修改调度、完整 EBNF 和目标 ABI 实现继续按决策清单推进，不因基础提案而视为已经完成。
